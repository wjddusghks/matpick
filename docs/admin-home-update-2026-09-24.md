# 관리자 작업 화면 및 메인 카드 개선

## 식당 메뉴 관리

식당명 아래에 프로그램·시즌·회차 배지를 표시하고, 선택한 식당의 상세 편집 헤더에서는 출처 링크를 제공합니다. 방송 회차 필터는 선택한 주제에 맞춰 좁혀집니다. 검색은 메뉴·주소 외에 방송명·회차·방송일을 포함하며 `EP.12`와 `12회`를 같은 검색어로 처리합니다.

출처에 명시된 회차만 표시합니다. 목록 순번은 방송 회차로 바꾸지 않습니다. 방송일이 없는 자료는 날짜를 만들어 표시하지 않습니다.

## 사용자 제보 대시보드

관리자 첫 화면에서 전체 접수 수, 최근 50건 중 대기 수와 최근 제보 3건을 확인할 수 있습니다. 전용 제보함은 목록·상세 패널, 상태 필터, 현재 페이지 검색, 메뉴·가격 표, 주소·출처 대조 링크, 검토 상태 변경을 제공합니다. 모바일은 목록과 상세를 전환합니다.

기존 관리자 인증과 API를 사용합니다. 확인 완료는 처리 상태이며 공개 식당 등록과는 별개입니다. 페이지별 50건 조회를 유지하므로 상태별 수와 검색은 현재 페이지 기준임을 표시합니다.

## 메인

‘식당 고르는 순간마다, 맛픽.’을 검색창 위로 이동했습니다. 데이트·점심·회식·손님 대접·여행·혼밥 등 12개 상황을 반투명 카드의 가로 Marquee로 표시합니다. 한국어·영어 문구를 제공하며 일시정지 버튼, 마우스 올리기 일시정지, 동작 줄이기 설정을 지원합니다.

## 확인

- 테스트 123개 통과, TypeScript 검사 통과.
- 데이터 검사 오류 0건, 운영 빌드·번들 크기 제한·SEO 생성 통과.
- 데스크톱 및 모바일에서 메인과 제보함 레이아웃 확인. 모바일 가로 넘침 없음.
- 임시 합성 제보로 목록→상세→상태 변경→수치 갱신 확인. 검수 전용 파일은 제거함.
- 전현무계획 시즌 4 EP.12 필터에서 해당 식당 2곳 표시 확인.
- 메인 카드 일시정지 동작 및 실제 썸네일 11개 로딩 확인.
- 실제 운영 제보의 읽기·쓰기는 이번 UI 검수에서 실행하지 않음.
