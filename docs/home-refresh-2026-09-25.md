# 메인화면·검색 소개·광고 연결

## 적용 내용

- 사진이 들어간 상황 카드 12개를 페이지 맨 위로 이동. 카드 높이 PC 60px / 모바일 56px. 일시정지·동작 줄이기 설정 지원.
- 검색어 없이 버튼을 누르면 `/map?type=nearby`로 이동. 위치 권한이 없으면 동네·역 이름 검색 안내. 기존 별도 주변 지도 버튼 제거.
- 상단 문의하기와 지도·방송/유튜브별 목록·후기·제보 바로가기 추가.
- 관리자 레드리본의 화면, 공급 목록, 검색 병합, 인증된 카탈로그 요청을 제거. 기존 API 주소는 410 응답. 기존 일반 식당은 유지.
- 홈페이지 제목·설명·사이트 이름을 한글로 통일하고, 검색엔진용 HTML과 실행 후 메타데이터를 일치시킴. JSON-LD의 사이트명은 맛픽, 검색 경로는 실제 `type=query` 경로.
- 기본 언어는 한국어. 해외 IP나 브라우저 언어만으로 영어로 전환하지 않으며 하단 English 버튼에서 직접 선택 가능.

## Google 애드센스

2026-09-25 계정의 공식 광고 단위 관리 화면에서 반응형 디스플레이 광고 2개 생성:

| 배치 | 단위 이름 | 슬롯 |
| --- | --- | --- |
| 메인 탐색 바로가기 아래 | 맛픽 메인 탐색 하단 | 8346833187 |
| 메인 주제 목록 아래 | 맛픽 메인 주제 하단 | 1386673166 |

게시자: `ca-pub-5524713795080356`. 이 값들은 공개 광고 코드의 식별자이며 비밀 키가 아니다. `client/src/data/adsense.json`에 보관하고 환경변수로 재정의 가능.

광고 동의 후 `matpick.co.kr`, `www.matpick.co.kr`에서만 실제 요청한다. 로컬·미리보기에서 실제 광고를 요청하지 않으며, 광고 미배정 시 빈 슬롯을 접는다. 페이지별 자동 광고 추가는 설정하지 않았다. 빌드 시 게시자 메타 태그와 ads.txt가 함께 생성된다.

**실제 노출 제한:** 콘솔의 matpick.co.kr 상태는 '주의 필요 / 가치가 별로 없는 콘텐츠'이고 당시 ads.txt는 '찾을 수 없음'이었다. 코드 연결과 광고 단위 생성이 승인 완료를 의미하지 않는다. 배포 후 ads.txt 인식과 콘텐츠 재심사가 필요하다. 계정에는 지급 정보 추가·사이트 연결 안내도 표시되었으며 이 계정 정보는 수정하지 않았다.

## 검색 노출

검색결과의 사이트링크는 Google이 사이트 구조·검색어에 따라 선택하므로 개수·순서·반영 날짜는 보장할 수 없다. 이번 변경은 제목·설명·한글 사이트명·정적 링크·사이트맵 기반을 정비한 것이다.

- [Google 사이트링크 안내](https://developers.google.com/search/docs/appearance/sitelinks?hl=ko)
- [Google 사이트 이름 안내](https://developers.google.com/search/docs/appearance/site-names?hl=ko)
- [AdSense 광고 단위 안내](https://support.google.com/adsense/answer/9274025?hl=ko)

## 앞서 진행한 메뉴 조사

원본 1,017개 검색, 재조회 118개, 추가 대조 495건을 정리했다. 주소/출처와 가격이 연결된 항목 400개는 중복 제거 시 386곳, 메뉴명·가격 조합 4,195건이다. 추가 확인 607개는 별도 사유별 목록에 남겼으며 이 중 69개에는 기존 역사적 가격 자료가 있다. 검색 완료는 모든 지점·가격·영업 확인 완료와 다르다. 이번 조사 결과는 `deliverables/six-topic-pending-2026-09-25/`에 보존했으며 운영 식당 데이터에 자동 적용하지 않았다.

## 검증

- TypeScript 검사 통과. 주변 검색·길찾기·공유·삭제 API·기본 언어 테스트 12개 통과.
- Vite 배포 빌드, 번들 크기 검사, 식당 4,339개 정적 페이지 생성 통과.
- 생성된 HTML의 한글 제목/설명, 단일 JSON-LD, 검색 링크, 광고 계정 메타 태그, ads.txt, 광고 슬롯 2개와 레드리본 번들 제거 확인.
- 브라우저에서 빈 검색의 주변 지도 진입, 위치 권한 없는 상태의 대체 안내, 성수역 검색 결과, 문의 페이지 이동, 카드 일시정지, 한국어/영어 전환 확인.
- PC 및 390px·320px 화면 검토. 가로 넘침 없이 표시. 실제 Google 광고 요청은 로컬에서 실행하지 않음.
- 후속 요청에 따라 화면 변경과 조사 결과를 각각 커밋·푸시 대상으로 정리했다. 배포 완료 및 광고 승인 상태는 별도 확인이 필요하다.
