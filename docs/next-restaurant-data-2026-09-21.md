# 맛픽 다음 식당 수집 후보

2026-09-21 기준. 공개 데이터 3,426곳과 21개 주제를 대조했다. 아래 숫자는 **주제에 연결된 현재 식당 수**다. 같은 식당이 여러 주제에 속하므로 합산하면 안 된다. ‘1차 목표’는 조사할 후보 수에 대한 제안이며, 확보·영업 확인·재사용 허가가 완료된 신규 식당 수가 아니다.

## 등록할 데이터와 통과 조건

- 식당: 지점이 구분되는 이름, 도로명 주소, 좌표, 음식 종류, 영업 상태.
- 소개 이력: 프로그램·채널·가이드 ID, 회차·선정 연도·발행일, 원본 URL, 광고·협찬 표시 여부.
- 메뉴: 대표 메뉴 1~3개 이상, 확인된 가격만 입력, 주문 단위·인원 제한, 가격 확인일과 출처.
- 재사용: 제공 API·다운로드와 해당 이용 조건을 먼저 확인. 공개 열람 자체를 재사용 허가로 간주하지 않음. 사진·장문 소개·자막·타인의 후기·평점은 수집 범위에서 제외.
- 중복: 이름만 비교하지 않고 주소·지점·좌표로 대조. 이전 가게는 기존 ID에 새 주소를 덮어쓰기 전에 관계를 검토.
- 검수 결과: 공개 / 가격 미확인 / 지점 확인 필요 / 폐업·휴업 / 이용 조건 확인 필요로 구분.

현재 정규 메뉴 배열이 비어 있는 식당은 498곳, 정규 메뉴 중 가격이 하나도 없는 식당은 562곳이다. 대표 메뉴 문자열로 표시 가능한 경우가 있어 관리자 화면의 ‘메뉴 없는 식당’ 수와는 다를 수 있다. 새 데이터와 함께 이 누락분을 관리자 편집 화면에서 보강한다.
