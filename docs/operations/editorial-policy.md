# 맛픽 편집·해외 성장 실험 기준 — 2026-09-29

## 고정 운영과 14일 실험

- 실험 기간은 2026-09-29부터 2026-10-12까지다. 매일 11:00 Asia/Seoul에 작업을 시작하고 검수 완료 순서대로 즉시 발행한다.
- 기존 목표를 유지한다: 승인된 다섯 채널(네이버, Instagram, 카카오, Pinterest, Threads)마다 하루 한국어 2개와 영어 2개, 총 20개/일. 기존 공개·예약 목록을 먼저 대조해 중복을 막는다.
- 신규 예약, 신규 채널, DM, 불특정 댓글, 유료 광고비를 만들지 않는다. 실험은 현재 계정·현재 빈도·현재 게시 흐름 안에서만 한다. 당근은 계속 제외한다.
- 원인에 대한 현재 판단은 가설이다. 낮은 조회가 콘텐츠 주제 때문이라고 입증된 것은 아니다. 계정이 새롭고 실제 게시일과 비교 가능한 데이터가 너무 적으므로, 14일 동안 같은 형식·주제군을 비교해 판단한다.

## 소재 방향

- 일반적인 사용법 안내, 로고 중심 카드, 서비스 소개 반복의 비중을 낮춘다. 확인 가능한 식당 사실을 바탕으로 여행자의 구체적 선택 의도(동네/역 + 음식 + 예산)를 먼저 다룬다.
- 식당명, 정확한 지점, 메뉴·가격·수량, 주소, 확인일과 출처를 내부 sources 파일에서 대조한다. 확인되지 않은 식당·가격·영업 상태를 예시처럼 사실화하지 않는다.
- 영어 콘텐츠는 이미지 안의 문구도 영어로만 쓴다. 음식명은 필요한 경우 쉬운 영어 gloss와 한국어 원어를 함께 제공하고, 실제 확인된 정보만 넣는다. 영어 글에는 Matpick이 한국어 YouTube·TV 음식 콘텐츠를 바탕으로 식당·메뉴·위치를 소개한다는 설명을 유지한다.
- Instagram은 원본 3~5장 슬라이드의 저장 가능한 비교(예: 예산별, 역 출구별, 메뉴 단위별)를 우선한다. Pinterest는 관련 키워드를 제목·설명에 자연스럽게 넣은 검색 우선 evergreen pin과 지원되는 경우 원문 딥링크를 쓴다. Pinterest 공식 안내는 관련성 높은 title/description keywords와 모바일 시각물을 권장한다: https://create.pinterest.com/fundamentals/.
- Threads는 복제한 광고 문구 대신 짧고 유용한 질문 또는 선택 기준 하나를 네이티브 문장으로 쓴다. Meta는 일부 적격 게시물이 Instagram·Facebook에 추천될 수 있고 insights와 link visits를 제공한다고 설명하지만, 추천은 보장되지 않는다: https://about.fb.com/news/2025/03/new-threads-features-more-personalized-experience-you-control/. 유용한 대화가 도움이 된다는 안내를 참고하되, 답글 권한을 확대하거나 무차별 참여를 하지 않는다: https://about.fb.com/news/2024/10/find-your-community-with-new-threads-educational-insights/.
- 네이버는 동네/역 + 음식 + 이용 목적 또는 예산처럼 검색 의도가 드러나는 제목·첫 문단으로 쓴다. 사실을 과장하지 않고 메뉴·가격·위치와 확인일을 제공한다.

## 링크와 성과 기록

- 링크를 지원하는 게시물은 `utm_source`(instagram/threads/pinterest/naver/kakao), `utm_medium=social`, `utm_campaign=international_20260929_14d`, `utm_content`(날짜·언어·주제·형식 식별자)를 넣는다. 각 값은 영문 소문자·숫자·밑줄·하이픈만, 80자 이내로 만든다. 예: `20260930_en_busan_soup_carousel`. 영어 링크에는 사이트 영어 모드를 여는 `lang=en`을 쓰되 실제 배포에서 작동하는지 확인한다. 링크를 지원하지 않으면 UTM을 억지로 만들지 않는다.
- Instagram 프로필 링크는 링크가 있다는 사실만 안내할 수 있다. 클릭 가능한 캡션 링크라고 주장하지 않는다.
- 각 게시물의 24시간 및 7일 시점에 다음을 따로 기록한다: impressions, reach, saves, profile visits, link clicks, site visits. 플랫폼이 지표를 제공하지 않으면 null로 기록하고 0으로 추정하지 않는다. link clicks와 site visits, 실제 매장 방문은 서로 바꾸어 쓰지 않는다.
- 비교는 같은 채널 안에서 형식·언어·주제군을 맞춘다(예: 기존 how-to/로고 카드 대 새 동네+음식+예산 비교). 게시물 수와 관측 창이 다른 경우 결론을 내리지 않는다. 실험 종료 시 지표 차이는 연관성으로만 보고하며 원인으로 단정하지 않는다.

## 검수 경계

- 공개 카피의 해시태그, AI 일러스트 표시, 경쟁 서비스명 제외, 검증 URL·확인일 보존 기준은 기존 검수 규칙을 계속 적용한다.
- 사실이 부족하면 초안을 보존하고 누락 수량을 기록한다. 새 계정·약관 동의·보안 설정·DM/댓글·광고 집행은 이 실험의 범위가 아니다.

## 계속 적용할 필수 기준

- 네이버 영어글 해시태그는 영어만(#Matpick), 한국어글은 한글만(#맛픽) 쓴다. 모든 채널에서 관련 태그를 포함하고 Instagram은 3~5개를 기본으로 실제 플랫폼 제한을 우선한다. 무관한 인기 태그·교환 태그·숨김 키워드는 쓰지 않는다.
- 네이버는 전체공개·검색허용을 확인한다. 공개 카피에 경쟁 맛집 서비스 이름이나 타인의 리뷰 표현을 넣지 않는다. 내부 출처 URL·확인일·이용 조건을 보존하고 의무 표시가 필요한 자료는 표시 없이 재사용하지 않는다.
- 맛픽 운영팀 큐레이션임을 밝히고 방문·시식 경험, 맛·대기시간·현재 영업 보장을 만들지 않는다. 가격은 지점·수량·확인일을 확인하고 방문 전 재확인 안내를 넣는다. AI 그림은 실제 음식 사진/정확한 지도로 소개하지 않고 플랫폼 AI 레이블을 적용한다.
- 영어 글은 한국어 YouTube 맛집 채널·TV 음식 프로그램 소개 식당을 찾는 서비스임을 설명하되 모든 식당이 인기 있거나 공식 제휴라고 주장하지 않는다. 공공 가이드 자료는 실제 출처 유형을 구분한다. 영어 이미지의 고유명은 영문으로 표기하고 한국어 원문이 필요한 경우 본문에서 길찾기용으로 제공한다.
- 초안·태그는 GPT-5.6 Luna, 번역·사실 검수는 GPT-5.6 Sol, 반복 검사는 코드로 분담한다. 콘텐츠 ID·계정·언어·날짜·이미지·링크를 게시 직전 대조하고 공개 URL 또는 성공 목록 확인 후에만 발행 로그를 갱신한다.
