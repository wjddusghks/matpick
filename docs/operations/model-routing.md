# 작업별 모델 분담

2026-09-27 사용자가 GPT-5.5/5.6 등 용도별 모델 호출과 반복 작업 분담을 승인했다.

| 작업 | 기본 실행 방법 | 검수/상향 조건 |
|---|---|---|
| 게시 개수·중복·필수 필드·태그 누락 검사 | 로컬 코드, 모델 호출 없음 | 오류 항목만 모델에 전달 |
| 검증 완료 사실 묶음 → 짧은 초안·제목·태그 후보 | GPT-5.6 Luna / medium | 미확인 사실 추가, 어색한 번역, 출처 충돌 시 Sol |
| 자연스러운 영어 편집·사실 대조·다단계 UI·일반 코드 수정 | GPT-5.6 Sol / medium 또는 high | 해결되지 않은 복잡한 충돌만 상위 모델 |
| 고난도 설계·보안 경계·최종 통합 판단 | 현재 상위 모델 | 필요할 때만 사용, 반복 카피 생성에 사용하지 않음 |
| 이미지 생성 | 내장 imagegen | 텍스트 모델의 GPT-5.5/5.6 선택과 별개. 서비스 오류를 모델 변경으로 해결된 것처럼 설명하지 않음 |

현재 대화의 상위 모델 자체를 자동으로 변경하는 설정은 적용하지 않았다. 독립 하위 작업을 위 모델로 명시해 호출하는 방식이며, 자동화 프롬프트에도 같은 분담을 저장했다. 사용 가능한 모델 목록에 없는 모델은 호출하거나 대체했다고 주장하지 않는다. GPT-5.5는 플랫폼 제공 목록/적합성이 확인된 작업에서만 대안으로 선택한다.

작업마다 필요한 사실·파일·범위만 전달한다. 전체 대화를 복사하지 않고 재사용 가능한 체크리스트와 이미 검증한 사실 묶음을 쓴다. 같은 산출물을 여러 모델에 무조건 재작성시키지 않는다. 이미지 한 소재를 한국어·영어판에서 재사용할 수 있으면 재사용한다.

작은 모델을 쓴다고 토큰 수나 총요금 절약을 보장하지 않는다. 재시도와 검수까지 포함한 실제 소요량을 비교한다. API 별도 과금 작업이나 유료 이미지 생성 우회 경로는 자동으로 새로 연결하지 않는다.
