# 후기 연령대 표시

후기 작성자가 선택한 경우에만 `20대`, `30대` 같은 연령대를 공개한다. 소셜 로그인 제공자가 전달한 정보를 서버에서 처리하고, 생년월일 원문은 저장하거나 브라우저로 보내지 않는다. 클라이언트가 임의로 보내는 연령대는 무시한다.

- 네이버의 `age`, 카카오의 `age_range`를 제공받으면 해당 범위와 제공 기준을 보관한다. 카카오 범위는 한국 나이 기준이므로 만 나이 인증으로 표시하지 않는다.
- 이미 동의받아 제공되는 양력 생년월일이 있는 경우에만 한국 날짜와 생일 경계로 만 나이 구간을 계산한다. 이번 설정에 생일·출생연도 권한을 추가하지 않는다.
- 연령대·제공 기준·확인 시점은 만료 30일의 기존 서버 서명 토큰에 포함한다. 정보 누락·미성년 구간·추정 불가능한 범위는 표시하지 않는다.
- 공개 동의는 후기별 기본 해제다. 공개한 후기에는 연령대, 기준, 확인 시점, 동의 시점, 동의 버전만 저장한다. 연령대는 작성 당시의 참고 정보다.
- 공개를 해제해 다시 등록하면 식당 후기와 전체 후기 피드에서 함께 제거된다. 기존 후기를 임의로 역산해 채우지 않는다.
- 소셜 로그인은 별도의 나이 본인인증이 아니다. 나이로 후기 작성 자격을 제한하지 않는다.

## 콘솔 활성화 상태

2026-09-20 확인: 네이버 앱은 `개발 중`으로 테스트 멤버만 이용할 수 있다. 연령대 선택 항목은 설정 화면에 준비했으나 **사용자 확인 전 저장하지 않았다**. 일반 이용자 로그인에는 네이버 검수가 필요하다. 카카오 개발자 콘솔은 사용자 로그인을 기다리고 있어 제공 권한을 아직 변경하지 않았다. 따라서 코드 배포와 제공자 권한 활성화는 구분해야 한다.

권한 변경을 마친 뒤 연령대 제공에 동의하고 다시 로그인하면 작성 화면에 선택 항목이 나타난다. 제공하지 않은 회원도 후기를 쓸 수 있다. 실제 회원의 동의·나이를 가정한 테스트 후기는 운영 저장소에 등록하지 않았다.
