# 자동차 경로 조회 비용 제한

2026-09-20 변경. 검색·위치 허용·더 보기·렌더링만으로 Directions 5를 호출하지 않는다. 사용자가 식당의 `자동차 시간·거리 확인`을 누르면 한 곳만 조회한다. 기본 길찾기는 네이버지도 외부 링크이며 이 서버 API를 호출하지 않는다.

- 브라우저: 같은 출발점·식당의 진행 중 요청을 합치고, 정상 결과 5분·실패 30초 캐시. 자동 재시도 없음.
- 서버: 같은 출발점·식당 정상 결과를 공유 Redis에 5분 캐시. 출발 좌표는 Redis 키에 평문으로 넣지 않고 해시하며, 결과에는 거리·시간만 저장한다.
- 새 네이버 요청 직전에 Redis Lua로 일·월 한도를 원자적으로 확인하고 함께 차감한다. 실패한 제공자 호출도 예산에 포함한다.
- 사이트 전체 최대 **하루 100건 / 월 1,000건**, 한국 시간 달력 기준. `ROUTE_DAILY_REQUEST_LIMIT`, `ROUTE_MONTHLY_REQUEST_LIMIT`는 더 낮출 수 있고 `0`이면 신규 호출을 중단한다. 기존 300 설정도 100으로 제한한다.
- IP당 분당 6회. 예산 저장소가 없거나 오류가 나면 503으로 중단하며 프로세스별 임시 카운터로 우회하지 않는다. 한도 도달은 429, 사용자는 네이버지도 링크를 이용할 수 있다.

필수 공유 저장소: `KV_REST_API_URL`/`KV_REST_API_TOKEN` 또는 `UPSTASH_REDIS_REST_URL`/`UPSTASH_REDIS_REST_TOKEN`. 캐시·카운터의 TTL이 지나기 전에 운영자가 삭제하거나 저장소를 변경하면 누적 한도가 초기화될 수 있으므로 비용 통제용 키를 유지한다. 별도 서버·노출된 키의 직접 호출 및 Dynamic Map/Geocoding 요금은 이 API 한도에 포함되지 않는다.

공식 [요금표](https://m.ncloud.com/charge/price/ko)의 Directions 5 단가는 건당 5원(VAT 별도), 대표 계정 1개에는 월 60,000건 무료 이용량이 안내되어 있다. 무료 적용 조건·계정별 사용량은 콘솔에서 확인해야 한다. 이 배포의 월 1,000건이 모두 과금되더라도 **이 경로 API 자체는 월 5,000원(VAT 별도)** 수준으로 제한된다. 계정 전체 청구액의 보장은 아니다.

네이버 콘솔 현재 사용량·대표 계정 여부는 세션 만료로 이번 점검에서 확인하지 못했다. Vercel에서는 공유 KV 환경변수 존재를 확인했다(비밀 값은 열람하지 않음).

검증: `matpick_all/tests/route-budget.test.mjs`에서 요청 합치기·캐시 만료·자동 재시도 없음·한도 확대 차단·한국 날짜 경계·Redis 오류 시 차단·서버 캐시 재사용·한도 초과 후 제공자 미호출을 가짜 제공자로 확인한다.
