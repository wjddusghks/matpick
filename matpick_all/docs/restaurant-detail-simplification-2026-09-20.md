# 식당 상세 화면 간소화

사용자 요청: 기존 맛픽의 흰색·분홍색 디자인을 유지하고, 사진 없이 메뉴·사람들의 평·위치를 보고 결정할 수 있는 화면으로 정리한다. 기존 상세 기능을 모두 유지할 필요는 없다.

## 적용

- 메뉴·댓글·리뷰·방송·정보로 나뉜 탭을 없애고 한 화면으로 구성했다.
- 식당명, 대표 메뉴, 소개 출처, 주소와 길찾기를 먼저 보여준다. 웹은 방문 안내를 오른쪽에, 모바일은 식당명 아래에 배치한다.
- 메뉴는 대표 항목 우선 3개를 보여주고 전체 목록을 펼칠 수 있다. 메뉴 자체가 없으면 큰 준비 중 영역을 만들지 않는다.
- 방송·가이드별 식당 탐색 링크를 제공한다. 실제 영상 URL이 있을 때만 원문 영상 접기를 제공한다.
- 방문자 평점은 기존 맛픽 방문 후기만 집계한다. 출연 수나 출처 없는 외부 평점을 맛 점수로 사용하지 않는다. 실제 후기 본문을 보여주며 인위적인 요약을 생성하지 않는다.
- 후기 작성은 별점과 글에 집중한다. 기존 방문 사진은 개별 후기 안에서 펼쳐볼 수 있다.
- 댓글 UI, 별도 개인 평점, 주제 저장 설명 패널, 사진 모아보기와 사진 첨부 UI를 상세에서 제거했다. 기존 API, 저장된 댓글·개인 평점·주제·방문 사진 데이터는 삭제하지 않았다. 일반 찜과 공유는 유지한다.
- 전화·영업시간·시설은 있는 데이터만 표시한다. 폐업·이전·추천 보류 및 잘못된 좌표는 길찾기를 노출하지 않는다.
- 광고는 방문 안내 뒤에 배치한다.

## 확인

- TypeScript 검사, 기존 11개 데이터 테스트와 새 후기 보존 테스트 3개 통과.
- Vite 운영 빌드, 번들 크기 검사, 2,907개 상세 SEO 페이지 생성 통과.
- 브라우저에서 웹·모바일, 메뉴 펼치기, 메뉴 없는 식당, 폐업 식당, 공개 후기 조회를 확인했다.
- 로컬 읽기 전용 미리보기는 운영 후기 GET만 연결한다. 운영 리뷰 POST, 커밋·푸시·배포는 이번 변경에 포함하지 않았다.
