# 검색 화면·상세 화면 및 네이버 길찾기

## 검색 결과

- 왼쪽 관련 주제 레일과 모바일의 큰 프로그램 이미지 띠를 제거하고 식당마다 방송·영상·가이드 소개 배지를 표시한다. 호버, 클릭, 키보드, 모바일 탭으로 출처 설명을 확인할 수 있다.
- 처음 6곳을 표시하고 하단의 `맛집 N곳 더 보기`로 최대 6곳씩 추가한다. 검색어·선택 식당·펼친 개수는 URL에 보존한다.
- 내 주변 검색에서 현재 반경에 후보가 6곳뿐이어도 더 보기 버튼을 유지한다. 요청한 개수에 맞춰 반경을 확장해 가까운 후보를 추가한다.
- 위치가 있으면 현재 위치의 **직선거리** 순으로 정렬한다. 도로 거리나 이동 시간 순이라고 표시하지 않는다. 위치가 없으면 기존 검색 순서를 유지한다.
- 모바일·데스크톱 검색 목록 위에 기존 Kakao AdFit 광고를 다시 배치한다. 기존 운영 광고 단위·반응형 설정을 재사용한다. 로컬 환경에 광고 단위가 없으면 노출하지 않는다.
- 공유창은 정식 matpick.co.kr 주소와 링크 복사를 제공한다. Clipboard API 실패 시 선택 기반 복사 및 직접 선택 안내를 제공한다.

## 자동차 거리·시간 및 길찾기

- 사용자 결정에 따라 **네이버 자동차 길찾기만 사용**한다. ODsay 호출·환경변수·대중교통 UI를 제거했다. ODsay 등록, 키 발급, 유료 신청, 외부 문의는 진행하지 않았다.
- 거리·시간 카드와 길찾기 버튼 모두 네이버지도로 연결한다. 도착 좌표·식당 이름과 유효한 출발 좌표를 전달하고 자동차 탭을 지정한다.
- NAVER Maps Directions 5 응답의 실제 도로 거리와 조회 시점의 소요 시간을 표시한다. duration은 밀리초를 분으로 변환하며, 직선거리로 시간을 추정하지 않는다.
- 더 보기로 추가된 식당도 최대 6곳씩 나눠 조회한다. 이미 조회한 식당은 메모리 캐시를 재사용한다. 캐시는 출발 좌표·위치 갱신·식당 ID를 구분하며 최대 300개, 일반 3분/조회 실패 30초이다. 주기적인 자동 호출은 없다.
- 검색·위치 변경 시 이전 요청을 취소하고 네트워크·한도 오류가 생기면 추가 배치 요청을 중단한다. 조회 불가 시 네이버지도 확인 링크를 제공한다.
- 서버는 실제 공개 식당 ID 최대 6개만 허용한다. 임의 목적지, 추천 보류·휴폐업 식당, 잘못된 좌표를 거부한다. same-origin, IP 분당 제한, 공유 일일 제한, 타임아웃을 유지한다.
- 기존 브라우저 코드 호환용 서버 응답에 `transit: not_configured`만 남겨 두었으며 외부 대중교통 API는 호출하지 않는다.
- 좌표·비밀키·원본 경로 응답을 서버 로그나 분석 이벤트에 기록하지 않는다. 개인정보 안내는 네이버 자동차 조회 기준으로 갱신했다.

## 상세 화면

- 메뉴와 가격을 기본 5개 표시하고 전체 메뉴 펼치기를 제공한다.
- 기존 데이터에 가격이 없으면 `가격 미확인`, 메뉴 자체가 없으면 확인된 정보가 없다는 안내를 표시한다. 가격을 추정하거나 만들어 넣지 않는다.
- 위치와 길찾기에 높이 190px의 네이버 지도를 표시하고 식당 위치를 마커로 표시한다. 줌 버튼을 제공하며 페이지 스크롤을 방해하지 않도록 지도 드래그·휠 확대는 끈다.
- 주소 복사, 네이버 길찾기, 맛픽 지도 보기, 네이버 매장 검색 링크를 제공한다.

## 운영 설정

2026-09-20 기존 네이버 Maps 애플리케이션의 Directions 5 활성화를 확인하고 Vercel Production에 서버 전용 Secret `NAVER_MAP_API_KEY`를 등록했다. 비밀키는 저장소나 브라우저 빌드에 넣지 않는다.

ID는 `NAVER_MAP_API_KEY_ID`, 생략 시 기존 `VITE_NAVER_MAP_KEY_ID`를 사용한다. 기존 서버 변수 `NAVER_MAP_CLIENT_SECRET`도 호환한다. 비밀키에는 `VITE_` 접두사를 붙이지 않는다.

운영 KV 저장소로 일일 요청 제한을 공유한다. 기본 `ROUTE_DAILY_REQUEST_LIMIT=300`은 최대 6개 식당을 담은 배치 요청 수 제한이다. 네이버 콘솔 자체 한도도 유지한다.

공개 출발점 성수역에서 소문난성수감자탕까지 실제 운영 API의 네이버 응답을 확인했다(527m, 검증 시점 5분). 실사용자의 현재 위치로 테스트하지 않았다.

## 검증

- TypeScript 검사, 검색·경로·공유·식당·후기 관련 테스트 23개 통과.
- 프로덕션 빌드, 번들 크기 검사 및 식당 2,907개 SEO 사전 렌더링 통과.
- 브라우저에서 성수역 검색 6곳 → 더 보기 후 11곳, 검색어 유지 확인.
- 네이버 링크에서 출발지·도착지 보존 및 자동차 탭 선택 확인. 출발지 없는 링크도 식당 도착지를 유지한다.
- 390px 모바일과 데스크톱 상세 화면의 지도·메뉴·가격 및 전체 메뉴 펼치기 확인.
- 실제 광고는 운영 환경의 기존 AdFit 설정으로 배포 후 확인한다.
