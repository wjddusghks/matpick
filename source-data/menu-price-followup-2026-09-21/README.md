# 가격 자료 70개 후속 반영

2026-09-21 공개자료 조사에서 가격 자료·후보가 있었던 70개 **기존 기록**을 보존한다. 현재 매장 가격을 70곳 모두 확정했다는 의미는 아니다.

- `price-evidence-70.json`: 70개 전체의 주소, 지도 동일 지점 대조, 출처, 자료 갱신일, 가격 후보, 다음 확인 작업. 배달 가격은 별도 배열로 보존한다.
- 동일 상호·주소·층수와 연결된 지도 메뉴 스냅샷 **20개 / 메뉴 200개**는 앱에 반영한다. 기존 조사 분류의 공개 가격 14개와 가격 후보 그룹에 있던 지도 메뉴 보유 6개다.
- 나머지 **50개**는 가격 검토 메모만 반영한다. 기존 메뉴·가격·수집일을 덮어쓰지 않는다. 후보의 상세 출처는 이 폴더의 원자료에 보존해 전체 지도 데이터 다운로드를 불필요하게 늘리지 않는다.
- 가격이 없는 메뉴는 추정하지 않으며, 상차림비·배달가를 일반 식사 가격으로 대입하지 않는다. 변동 가격은 메뉴명에 있는 변동 표시를 유지한다.
- 기존 관리자 수정 `restaurant-overrides.json`이 최종 우선권을 갖는다.

재생성: 저장소 루트에서 `node scripts/build-menu-price-followup.mjs`, 이어서 `node matpick_all/scripts/generate-public-data.mjs`.

140개 영업 판단 유보 기록의 네이버지도 조사는 별도 작업이다. 이 커밋에서 폐업·주소·좌표는 변경하지 않는다.
