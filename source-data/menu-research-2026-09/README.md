# 메뉴 누락 882곳 보강

`queue.json`은 작업 시작 시점의 메뉴 누락 목록입니다. 이미 채운 식당을 다음 실행에서 다시 누락 대상으로 집계하지 않도록 유지합니다.

저장소 루트에서 실행합니다.

```powershell
node scripts/collect-missing-menus.mjs
node scripts/collect-missing-menus.mjs --retry-identity
node scripts/build-menu-research.mjs
```

첫 명령은 미처리·일시 조회 오류를 이어서 처리하고, 두 번째 명령은 상호·주소 불일치 후보를 재검토합니다. 검색 질의가 같으면 저장된 후보를 다시 비교합니다. 공개 메뉴는 카카오지도 동일 지점의 상세 정보에서 확인합니다. 요청은 최소 1초 간격이며 401·403·429가 나오면 멈춥니다. 인증·접근 제한을 우회하지 않습니다.

상호, 시도, 시군구와 도로명·건물번호 또는 지번을 대조합니다. 좌표만 일치하거나 이름만 같은 곳은 자동 반영하지 않습니다. 행정구역명 변경에 한해 100m 이내 좌표를 시군구 보조 근거로 사용하며, 이때도 상호·시도·번지 일치가 필요합니다. 기존 장소 ID가 있더라도 현재 상세 주소를 다시 확인합니다. 주소가 바뀐 경우 메뉴 수집만으로 임의 수정하지 않습니다.

`manual.json`은 공식 사이트 등에서 직접 확인한 추가 근거입니다. 사진·후기 원문·설명문은 복제하지 않고 메뉴명·가격과 원문 URL, 확인 시점을 기록합니다. 가격이 없거나 시가·0원인 항목은 가격을 비워 둡니다.

`report.md`에서 확보 수와 미확인 목록을 확인할 수 있습니다. 조회 완료는 882곳 모두의 가격 확보를 뜻하지 않습니다. 폐업·이전 표기, 주소 불일치, 메뉴 미공개는 각각 별도 상태로 남습니다. 공개 데이터에는 검증된 메뉴만 들어가며 운영자가 직접 지정한 restaurant-overrides.json을 우선합니다.
