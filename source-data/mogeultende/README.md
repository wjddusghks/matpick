# 성시경의 먹을텐데 데이터셋

2026-07-15 기준 성시경 공식 유튜브 채널의 일반 영상 중 제목에 `먹을텐데`가 포함된 영상을 수집하고, 국내 식당과 현행 장소 정보를 정규화한 데이터입니다. 맛픽 공개 데이터와 회차별 CSV에서는 해외 식당을 제외합니다.

## 범위와 회차 기준

- 공식 영상: 214편 (`2022-03-11` ~ `2026-06-29`)
- 회차: 공식 영상 업로드일 오름차순으로 맛픽에서 부여한 번호
- 국내 식당이 확인된 회차: 194편
- 국내 식당 방문 행: 204건
- 고유 국내 식당: 195곳
- 제외한 해외 식당: 15개 회차, 28곳
- 광고·행사·상호 미공개 또는 해외 제외로 식당 행이 없는 영상: 20편

## 파일

- `youtube-videos.json`: 공식 채널 영상 메타데이터와 전체 설명
- `episodes.json`: 회차별 영상과 식당 ID 연결
- `restaurants.json`: 정규화한 식당·주소·좌표·전화·메뉴·가격·영업시간·지도 정보
- `mogeultende-restaurants.csv`: 운영/검수용 회차별 평면 CSV
- `kakao-places.json`: 국내 식당의 카카오맵 장소 매칭 스냅샷
- `kakao-menus.json`: 카카오맵 메뉴·가격·요일별 영업시간 스냅샷
- `overrides.json`: 해외 제외 판정, 광고/행사편, 설명 예외 수동 보정
- `source.json`: 출처와 회차 정책

## 갱신

`matpick_all` 디렉터리에서 실행합니다.

```bash
pnpm collect:mogeultende
pnpm enrich:mogeultende:kakao
pnpm build:mogeultende
pnpm apply:mogeultende
```

카카오 장소 페이지의 메뉴와 요일별 영업시간은 동적 화면에서 수집한 스냅샷입니다. 가격·영업시간은 변경될 수 있으므로 앱에서도 수집일과 방문 전 재확인 안내를 함께 표시합니다.

## 검수 원칙

- 상호·당시 주소는 공식 영상 설명을 우선합니다.
- 현행 장소는 상호와 행정구역·도로명·번지 유사도를 함께 확인합니다.
- 폐점·이전·상호 변경 가능성이 있어 현행 지점을 확정하지 못한 국내 9곳은 당시 주소를 유지합니다.
- 해외편 영상은 회차 번호와 제외 사유만 유지하고 식당·방문 데이터에는 포함하지 않습니다.
