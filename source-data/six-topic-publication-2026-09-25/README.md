## 중복 및 정확성 처리

- 같은 지도 장소 ID와 같은 지점 주소, 또는 상호·도로명/지번·건물/호수 일치를 대조했다. 기존 ID·즐겨찾기·후기 연결을 유지한다.
- 같은 식당이 여러 주제에 등장하면 식당은 하나로 유지하고 소개 출처를 연결한다. 동일 영상의 중복 연결도 제외한다.
- 서로 다른 지점, 같은 지도 ID의 주소 불일치, 가까운 유사 상호, 영업 보류, 가격 충돌, 좌표 미확정은 자동 반영하지 않았다.
- 해외와 영구 삭제 기록을 제외한다. AI 보조 입력으로 표시된 가격만으로 메뉴를 추가하지 않는다.
- 기존 가격이 있는 메뉴는 덮어쓰지 않는다. 누락된 메뉴·가격만 보충하며 원래 주소·좌표도 유지한다.
- 메뉴별 자료 날짜 또는 `자료 기준일 미상`을 표시한다. 출처 조회일을 가격 적용일로 사용하지 않는다. 과거 가격과 기준일 미상 가격이 포함되며 현재 영업·가격 및 전체 메뉴를 확인한 결과는 아니다.
- 신규 장소 중 좌표는 확인했지만 음식 분류를 별도로 확인하지 못한 항목은 일반 `음식점`으로 분류한다.

- `observations.json`: 조사 상태, 식당·지점, 메뉴 가격, URL과 날짜, 원천 자료의 AI 보조 표시. 페이지 본문·사진·후기 전문은 포함하지 않는다.
- `publication.json`: 1,772건 각각의 반영·중복·보류 결정과 기존 가격 보존 기록.
