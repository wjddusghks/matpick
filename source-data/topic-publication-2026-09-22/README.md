# 새 주제 공개 연결 및 관리자 검토 목록

기준: 2026-09-22. 사용자가 승인한 **확인된 식당 공개 + 나머지 관리자 검토** 방식의 배치다.

## 반영 범위

- 신규 주제 10개를 메인·검색·탐색 목록에 연결한다.
- 기존 식당 586곳에 식당–주제 연결 782건을 추가한다. **신규 식당 생성은 0곳**이며, 기존 식당 3,548곳의 주소·좌표·메뉴·가격은 변경하지 않는다.
- 전체 조사 후보 22,117행을 인증된 관리자 `/admin/topic-research`에서 조회한다. 식당 고유 수가 아니며 동일 상호·지점의 중복 행과 주제 간 중복이 있다.
- 654행은 해당 후보의 모든 주제 연결을 완료했다. 24행은 일부 주제만 연결됐다. 일부 연결을 포함해 **21,463행은 추가 검토 대상**이다.
- 이는 소개 이력과 기존 식당의 연결 작업이다. 전체 식당 전수 검증, 현재 실제 영업 확인, 현재 가격 확보 완료를 의미하지 않는다.

## 공개 기준과 보류

1. 기존 공개 식당과 상호·주소(전체 도로명과 건물번호 또는 지번)를 대조한다. 이름만 같은 곳, 다른 시군구, 서로 다른 층·호수는 자동 연결하지 않는다. 인허가상 영업 기록과 정확히 일치할 때만 지번–도로명 주소를 보완한다.
2. 개별 공식 유튜브 설명/사전 대조 기록, KBS·SBS·MBC의 개별 방송 게시물을 소개 근거로 삼는다. SBS TV맛집의 프로그램별 목록, 검색 결과, 자막 추정 이름만으로는 공개하지 않는다. 각각의 근거에 상호·주소가 있는 경우에도 식당과 다시 대조한다.
3. 기존 제외 119곳, 추천 보류·폐업·이전·휴업 식당, 인허가 폐업/충돌 이력이 있는 후보는 새 주제로 노출하지 않는다. 인허가 미일치와 조사 범위 밖은 폐업으로 단정하지 않는다.
4. 더들리의 마포 진미식당, 흑백요리사 출연 김도윤 셰프의 윤서울은 `manual-associations.json`의 별도 공식 출처 대조를 적용한다. 셰프 관련 이력은 식당의 직접 방송 출연이나 현재 재직 주장과 구분한다.
5. 후보의 메뉴 단서·과거 가격은 관리자에만 제공한다. 현재 메뉴 및 가격으로 자동 덮어쓰지 않는다.

## 파일과 재생성

- `candidates.json`: 원문 전체 설명/자막/댓글을 제외한 상호·주소·메뉴 단서·인허가 대조·출처 스냅샷. 서버 전용.
- `catalog-baseline.json`: 작업 전 커밋 `d1ad6e1`의 최소 식당 식별 정보.
- `manual-associations.json`: 별도로 대조한 두 연결과 원문 링크.
- `publication.json`: 모든 후보의 공개 연결 결과 및 미확인 이유. 서버 전용.
- `summary.json`: 주제별 반영 집계.

저장된 스냅샷으로 공개 연결 재생성:

```sh
node scripts/topic-publication/build.mjs
cd matpick_all
node scripts/generate-public-data.mjs
```

`scripts/topic-publication/import-research.mjs`는 로컬에 보관된 `source-data/topic-census-2026-09-22` 연구 원본에서 최초 스냅샷을 만든 도구다. 원문 연구 자료와 API 키는 이 배치에 포함하지 않는다. 연구 스냅샷을 교체할 때는 기준 커밋과 수동 대조 결과를 함께 재검토해야 한다.

관리자 목록은 인증 후 서버에서 30행씩 제공하며, 상세 근거는 선택 시 가져온다. 읽기 전용 검토 목록이며, 연결된 기존 식당은 식당 편집 화면에서 수정할 수 있다. 후보 공개 승인 및 검토 상태의 수동 저장 기능은 이번 범위에 포함되지 않는다.

## 검증

- 신규 주제·주소/지점 식별·보류 식당 제외·관리자 인증/검색/페이지네이션을 포함한 테스트 22개 통과.
- TypeScript 검사, 공개 데이터 검사(오류 0건), Vite 빌드 및 SEO 사전 렌더링 통과.
- 이전 커밋 대비 기존 식당·메뉴·가격 레코드 전체 동일 확인.
- 데스크톱 및 390px 모바일에서 관리자 검색·상세 전환 확인. 관리자 테스트 화면은 별도 loopback 전용 fixture를 사용하며 운영 인증과 저장소를 변경하지 않는다.
- 지도 JavaScript gzip 1,074,921바이트로 1.1MB 제한 유지. 공개 식당 ID의 불필요한 자기 자신 별칭을 제거했다. 관리자 연구 원본은 공개 브라우저 번들에 포함하지 않는다.
